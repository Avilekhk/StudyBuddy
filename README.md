# StudyBuddy

StudyBuddy is a web-based peer tutoring booking platform designed for university students. It allows students to register as learners or tutors, find tutors by subject, view available time slots, and book tutoring sessions.

## Technologies

* PHP
* MySQL
* HTML5
* CSS3
* JavaScript
* WAMP Server

## Main Features

* Student and tutor registration
* User login and authentication
* Tutor search by subject
* Tutor availability management
* Tutoring session booking
* Student and tutor dashboards
* Contact page
* MySQL database for storing users, subjects, availability and bookings

## Purpose

The project aims to provide a simple central platform for university students to connect with peer tutors instead of relying on word-of-mouth, group chats or noticeboards.
